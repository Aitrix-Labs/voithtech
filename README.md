# VoithTech

Corporate site for **voithtech**, modeled on the Voith.com layout and visual system (hero carousel, business fields, services, careers, news).

## Develop

```bash
npm install
npm run dev
```

Local URL: [http://localhost:5177/voithtech/](http://localhost:5177/voithtech/)

## Build

```bash
npm run build
npm run preview
```

GitHub Pages base path is `/voithtech/`.
